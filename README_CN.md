## 个人简介

李宜哲，电气工程专业博士，现工作于中国电力科学研究院有限公司，主要从事直流输电控制保护系统、电力系统自动化及综合能源系统相关研究与工程工作。

曾留学英国和美国，先后在英国斯特拉斯克莱德大学、美国肯塔基大学学习，具备国际化教育背景和英文沟通能力。

曾任职于中国能源建设集团华北电力试验研究院有限公司，从事电气专业调试工作，具有工程师职称。参与多项大型火电机组、燃气—蒸汽联合循环机组、分布式能源及压缩空气储能项目的现场调试，具备较丰富的工程实践经验。

目前工作重点包括新一代控制保护平台研发、直流输电及新能源场景控制保护技术、保护配置方案审查、系统测试及工程技术支持等。具备科研创新、工程实施和项目协调相结合的复合型能力。
